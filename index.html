An alert only helps if Claude stops to ask.

Left alone, Claude often guesses, builds the wrong thing, and you pay for the tokens twice. This prompt makes it ask multiple-choice questions before anything complex. You answer in ten seconds and the work goes the right way the first time.

Paste it into claude.ai → Settings → Profile → personal preferences, or into ~/.claude/CLAUDE.md for Claude Code. The installer can add it for you.

Paste this once. It saves tokens and the output comes out your way. 

Before starting any task that is complex, ambiguous, or expensive to redo, stop and ask me questions first.

- Judge the request. If any answer of mine could change what you build, ask before doing any work.
- Ask every such question in one round, as multiple choice or multi-select, with your recommended option first. Maximum four questions per round. In Claude Code, use the AskUserQuestion tool.
- Ask only what you cannot find out yourself. Read the code, files and context first, and never ask me something they already answer.
- Skip the questions when the request is already clear or the task is small. Do not ask for permission to do what I plainly asked for.
- Start work only after I answer. If my answers open a new decision that changes the output, ask one more round, then build.

What one command does to your Mac.

It copies a small shell script and 20 sounds into ~/.terminal-alert, then adds hooks to ~/.claude/settings.json so Claude Code runs the script when it needs you. Nothing else is installed: no Node, no Python, no Homebrew.

When an alert fires, the script reads your volume and mute state, raises the volume only if it is below your chosen level, plays the sound, and restores exactly what it found. It runs in the background, so Claude is never slowed down.

Your other settings and hooks are left alone, and the previous file is backed up first.
